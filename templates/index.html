From raw text to useful insight.

An explainable, offline NLP pipeline built for exploration.

INPUT

Bring the conversation

Paste one post per line or upload a CSV with a text column. Empty entries and exact duplicates are removed. The included electric-vehicle dataset is an example, not a live feed.

SENTIMENT

Preserve the meaning

VADER is a lexicon and rule-based sentiment analyzer. It considers negation, emphasis and punctuation. URLs are removed, but words such as “not” are preserved.

Compound score ≥ 0.05: positive. ≤ −0.05: negative. Everything between: neutral.

TOPICS

Find recurring themes

TF-IDF weights distinctive terms. Non-negative Matrix Factorization groups related terms into up to five topics. Each post is assigned to its strongest group. For fewer than four posts, the app shows top keywords instead.

INTERPRETATION

Know the boundaries

This English-language baseline can misread sarcasm, mixed sentiment, slang and domain-specific language. Scores are not confidence levels. Evaluate against human labels before making accuracy claims.

No posts are stored in a database. Results remain in browser memory until refreshed; export CSV to keep them.

A small, inspectable stack

Browser interface → Flask API → VADER + scikit-learn → JSON results

The server runs on your laptop at 127.0.0.1. Keep the terminal open during your demonstration. This version does not collect live social-media posts.
